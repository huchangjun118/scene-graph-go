# scene-graph-go

场景图与空间查询内核，供上层渲染与交互逻辑复用。核心包为 `scenegraph`。

## 功能概览

- 层级场景图：节点挂载 / 重挂载 / 移除，局部变换沿层级传播为世界变换。
- 增量更新：局部变换或包围盒变化只重算受影响子树，其余节点状态不变。
- 空间查询：世界空间包围盒区域查询、视锥查询、射线最近命中查询。
- 并发模型：多读单写，查询与更新并发安全，更新原子提交、可取消。
- 导出 / 恢复：场景快照导出与幂等导入。
- 确定性：固定输入序列下，遍历顺序与查询结果逐条可复现。

## 坐标约定

- 右手坐标系。
- 矩阵为 4x4 **列主序**（`Mat4[0..3]` 为第一列），向量按列向量处理。
- 组合变换 `m.Mul(o)` 表示先应用 `o` 再应用 `m`。
- 世界变换沿层级自顶向下合成：`world(n) = world(parent(n)) * local(n)`，根节点 `world = local`。
- 节点包围盒（`AABB`）定义在节点局部空间，世界包围盒由局部包围盒的 8 个角点经世界变换后重新取轴对齐包围盒得到。
- 视锥由视图-投影组合矩阵经 Gribb-Hartmann 方法提取，裁剪空间约定为 OpenGL 风格 `x,y,z ∈ [-w, w]`。

## 修改模型：事务与原子提交

所有修改通过事务进行：

```go
tx := s.Begin()
tx.Add("child", scenegraph.RootID, scenegraph.Translation(1, 0, 0), bounds)
tx.SetLocal("child", m)
tx.Attach("child", "otherParent")
tx.Remove("old")
err := tx.Commit(ctx)
```

- `Commit` 在写锁内按顺序校验并应用全部操作；任一操作失败（含环检测）或 `ctx` 取消时，**已应用的操作全部回滚**，场景保持提交前状态，修订号不变。
- 空事务为 no-op，不递增修订号。
- 环检测：把节点挂到自身或其任意后代之下会被拒绝（`ErrCycle`），原有结构保持不变。
- 根节点（`RootID == ""`）永远存在，不能被移除或重挂载。

## 查询语义

- **遍历顺序**：深度优先，子节点按挂载先后顺序。`VisitAll`、区域查询、视锥查询的结果顺序均与此一致。
- **区域查询 `QueryRegion`**：返回世界包围盒与给定区域相交的节点；边界接触（含单点/单面接触）视为相交；空包围盒永不命中。
- **视锥查询 `QueryFrustum`**：返回世界包围盒与视锥相交或位于视锥内的节点（逐平面 positive-vertex 测试，是保守测试：不会漏报，极端情况下可能多报）。
- **射线查询 `RayCast`**：返回与节点世界包围盒相交且距离最近的节点。边界行为定义如下：
  - 射线起点位于包围盒内（含边界）：命中，距离 `T = 0`。
  - 射线与包围盒相切（进入距离等于离开距离）：视为命中。
  - 射线方向某分量为 0 且起点不在对应 slab 范围内：未命中。
  - 包围盒整体位于射线背面（离开距离 < 0）：未命中。
  - 尺度退化（如某轴缩放为 0）时包围盒被压成薄片/线段/点，仍按上述 slab 规则判定：垂直穿过薄片的射线命中，平行但偏离薄片平面的射线不命中。
  - 多个节点命中距离相同：按遍历顺序取先者，结果确定。

## 并发模型

- 多读单写：查询在内部读锁内完成；`Commit` 在写锁内原子完成。
- 节点的所有访问器（`World`、`WorldBounds`、`Children` 等）各自获取读锁，任何时刻读到的都是某次已提交状态的完整字段值，不会读到撕裂的世界变换。
- `VisitAll` 在持锁期间只建立节点快照，用户回调在锁释放后执行，回调内可自由调用节点访问器。

## 导出与恢复

- `Export` 返回 `Snapshot`，节点按遍历顺序排列，父节点一定先于子节点出现；同一场景重复导出结果逐字节一致。
- `Import` 把快照合并进场景：已存在的节点 ID 原样跳过（不重复创建、不修改既有数据），缺失节点按记录补齐；整个导入是单个原子事务，失败时场景不变。因此对同一份数据重复导入是幂等的。

## 可复现性

内核不使用任何随机源与 map 迭代顺序：节点索引仅用于按 ID 查找，所有遍历都沿有序子节点列表进行。固定输入操作序列下，遍历顺序、查询结果与导出快照逐条可复现。

## 测试

```sh
go test ./... -race -count=1
```

覆盖：变换传播与增量更新、重挂载与环拒绝、事务回滚与取消、区域/视锥/射线查询（含退化尺度、相切、起点在盒内等边界）、多读单写并发（`-race`）、导出恢复与幂等导入。
