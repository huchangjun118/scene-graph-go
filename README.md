# scene-graph-go

场景图与空间查询内核，供上层渲染与交互逻辑复用。纯 Go 实现，无第三方依赖。

## 功能概览

- 层级挂载与变换传播：父节点变换改变后，全部后代的世界变换同步更新；
  挂载成环时操作被拒绝且场景保持原状。
- 增量更新：单节点/子树的局部变换变化只重算受影响的后代。
- 世界空间区域查询（AABB）与视锥查询。
- 射线命中查询（最近命中，边界行为确定，见下）。
- 多读单写并发：查询与更新并发安全，读者不会看到撕裂的世界变换；
  事务式更新被取消时场景不停留在中间状态。
- 场景导出/恢复（JSON）：恢复后层级、节点标识与查询结果一致；
  重复导入幂等，不产生重复节点。
- 确定性：固定输入序列与随机种子下，遍历顺序与查询结果逐条可复现。

## 坐标约定

- 右手坐标系，`float64` 精度。
- `Mat4` 为列主序 4x4 仿射矩阵，点变换 `v' = M * v`。
- 节点局部变换为 TRS：`M_local = T * R * S`（先缩放、再旋转、再平移）。
- 世界变换沿层级复合：`M_world = M_parentWorld * M_local`，根节点父变换为单位矩阵。
- 包围盒为轴对齐盒（AABB），Min/Max 为闭区间；世界包围盒由局部盒 8 角点
  经世界变换后重取包围得到。

## 查询语义

| 查询 | 语义 |
| --- | --- |
| `QueryRegion(box)` | 世界包围盒与区域相交（闭区间，接触算相交）的全部节点 |
| `QueryFrustum(f)` | 世界包围盒与视锥相交或在内部的全部节点（保守判定：仅当完全位于某裁剪平面外侧才排除） |
| `Raycast(ray)` | 命中世界包围盒的最近节点，返回命中参数 `t` |

所有查询返回节点 ID，顺序为场景确定遍历顺序（根列表按成为根的顺序、
子节点按挂载顺序、先序遍历），并反映最近一次已提交的变换。

### 射线查询边界行为（确定行为）

- 命中距离取进入参数 `tNear`；射线起点在包围盒内时 `tNear = 0`。
- 射线与包围盒相切（擦边/擦面）视为命中。
- 节点尺度退化（某轴缩放为 0，盒退化为面/线/点）时仍按退化后的盒做
  slab 相交，行为与常规盒一致。
- 多节点命中距离相同时，按场景遍历顺序取先者。
- 方向向量无需归一化，返回的 `t` 与方向尺度一致。

## 并发模型

`Scene` 内部使用 `sync.RWMutex`：查询持读锁、变更持写锁。读者始终看到
最近一次完整提交的状态。`Scene.Update(fn)` 提供事务语义：`fn` 在私有
副本上执行，返回错误（取消）时场景保持原状，成功时变更原子提交。

## 导出与恢复

```go
data, _ := scene.Export()   // 确定顺序的 JSON
err := scene.Import(data)   // 原子生效、幂等；非法数据整体回滚
```

导入为合并语义：已存在的节点按导入数据更新，未出现在导入数据中的
现有节点保持不变。

